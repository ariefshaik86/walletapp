# 💰 WalletApp - Reward Based Web Application

WalletApp is a reward-based web platform where users can register, earn bonuses through referrals, and manage their digital wallet securely.

---

## 🚀 Live Demo
🔗 http://walletapp.10001mb.com/

---

## ✨ Features
- User registration and login system
- Referral system with bonus rewards
- Wallet management (earn, track balance)
- OTP-based authentication
- Secure session handling
- Responsive UI

---

## 🛠 Tech Stack
- PHP (Backend)
- MySQL (Database)
- HTML, CSS, Bootstrap (Frontend)

---

## 🤖 AI Tools Used
- ChatGPT (for debugging, backend logic, and optimization)

---

## 📂 Project Structure
- `index.php` – Entry point
- `register/login` modules
- `wallet management system`
- `database integration`
